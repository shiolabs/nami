nami is open source, its own files move to /nami, and you can install nami without its app, or remove the app for good.

## Open source
- nami and the nami app are open source under the MIT licence, at github.com/shiolabs/nami. nami is made by Shio Labs.

## Where nami keeps its files
- nami's own files are in /nami now, at the top of the computer. They move there by themselves as nami updates; /nix/var/nami still leads there. Apps stay in /nix.
- On a computer whose / can't hold them, such as Fedora Silverblue, they stay in /nix/var/nami.
- On namiOS, Files no longer shows /nix. Press Ctrl+H to see it.

## Installing
- To install nami without its app, add --no-app to the install command: curl -fsSL https://namios.dev/install | sh -s -- --no-app. To add the app later, run sudo nami install nami-gui.
- On namios.dev, the install box has a switch between the command with the app and the command line alone.

## The nami app
- The notes under Installed and System Apps say System, as the tags beside each app do.
- Move to namiOS shows today's namiOS desktop.

## Fixes
- sudo nami remove nami-gui removes the app for good. Updates no longer bring it back.
- The installer finds the desktop on computers with only Wayland sessions, so the app is offered there too.
- nami's address is hi@shiolabs.dev.
