nami runs on Macs as a preview, and on 64-bit ARM computers with Linux.

## Macs (preview)
- nami runs on Macs with Apple silicon and on Intel Macs. Install it with the same command in Terminal: curl -fsSL https://namios.dev/install | sh
- Install, remove, search and upgrade apps from the catalog, apply your user.nami, and use projects with nami shell and nami run, as on Linux.
- One user.nami works on Linux and on a Mac: services, desktop settings, Flathub apps and bundles are Linux features, and nami leaves them out on a Mac and says so.
- The nami app comes with it: Discover, Installed, Your Setup, Projects and History, with the Mac's own menus and shortcuts. It opens an app you've installed from the app's page.
- Every package comes ready-built from the binary cache. A package without a Mac build says it isn't ready-built for Mac.
- Apps you install aren't added to your Applications folder yet.

## ARM Linux
- nami runs on 64-bit ARM computers with Linux: a Raspberry Pi 4 or 5 with a 64-bit system, ARM servers and Snapdragon laptops. The installer is the same.
- Everything nami does on Linux works there too: apps, your user.nami with services and settings, projects, Flathub apps that have an ARM version, and bundles for ARM computers.
- nami's app isn't on ARM yet. The installer leaves it out, and the command line has everything.

## Search
- The package search on namios.dev shows where each package runs, Linux, Mac or ARM Linux, and filters by it, starting with the computer you're on.
