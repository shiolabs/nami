Run any command without installing it with nami try, and namiOS's window is nami try-os.

## Commands
- nami try runs a command without installing it: nami try cowsay hi. The package is fetched if it isn't on the computer yet, run, and left for nami gc. nami run-once still works.
- The command for trying a namiOS computer in a window is now nami try-os.
