nami now writes the recipe for a project from its link and builds it, and the install script works again on every Linux distribution.

## Recipes and Python
- nami recipe from-url writes a recipe from a project's link: a GitHub, GitLab or Codeberg repository, or any tarball or zip. nami recipe new does the same for a folder.
- Rust, Go, Python and Node.js projects build as they are, as do projects built with Meson, CMake, configure or make.
- The libraries a project needs are found in the catalog and filled in for you.
- Checksums are recorded the first time a recipe builds, so there are none to write by hand. A download that changes later is refused, with what changed.
- nami recipe update moves a recipe to its project's newest release.
- When a build fails, nami says what's missing in plain words, and the line to add.
- A Python can come with its packages, such as numpy and requests, in one line of your file, a project's or the system's.

## Your File and the System's
- nami apply, undo, config and upgrade act on your own file, user.nami; with sudo, on the system's, system.nami. --user and --system name the file outright.
- The computer's file, computer.nami, becomes system.nami by itself. The old name keeps working.
- Every change says which file it changed, and how to undo it.
- nami list and nami status show the system's apps and yours, each labelled.
- Your very first install can be undone too.
- In Settings, apps for everyone are now System Apps.

## namiOS
- Camera takes pictures and video with your webcam.
- Wallpaper effects: Dots, Blur, Mono and Dim, in Settings › Appearance › Wallpaper. The lock screen and the login screen show them too.
- namiOS starts on black, as a Mac does, with a sharper mark.
- nami iso makes namiOS as an ISO: try it in a VM or from a USB drive, then install it in three steps, next to Windows or on a disk of its own.
- To make a USB drive your own computer, put your system.nami in the namios folder on it (computer.nami still works). On Windows and Mac the drive shows up as NAMIOS, ready to copy the file onto. This works for drives made with nami usb and nami iso.
- AirPods show pictures of your own model in their card, Control Center and Settings.

## Fixes
- The install script stopped on Ubuntu, Debian, Fedora and Arch, saying the download wasn't signed. It installs again, and says where nami goes and what to try first.
- A new computer gets only nami's own names for its files and folders.
- Searching for a tool by its name, such as ripgrep, shows that tool.
- Changing a setting while your file still had an older name could empty it. Your apps, aliases and settings now stay. The system's file had the same problem.
- When another nami is busy, nami says what it's waiting for instead of waiting silently.
- A download that's tried again says which server and why, in plain words.
- An app in a project that has no ready-made download is named before anything downloads, with whether your computer can build it.
- A recipe whose source is outside its folder builds again when that source changes.
- A download with a bad signature is now an error, instead of the app being left out without a word.
- nami can download from a mirror of nixos.org's cache, such as a company proxy. Everything is still checked against nixos.org's key.
- The uninstaller names every folder that holds the system's files.
